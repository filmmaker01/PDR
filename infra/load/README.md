# Нагрузочная проверка

Сценарии для k6. Запускаются на staging вручную перед пилотом и после заметных изменений в выдаче списков.

## Чтение списков

```bash
BASE_URL=https://api.staging.example \
TOKEN=<access-токен владельца мастерской> \
WORKSPACE_ID=<uuid мастерской> \
k6 run infra/load/read-load.js
```

Проверяет «Сегодня», список заказов, список клиентов и календарь под нагрузкой до 200 запросов в секунду. Пороги: доля ошибок ниже 1 %, 95-й процентиль времени ответа меньше 400 мс.

Токен берётся из ответа `POST /v1/auth/telegram/miniapp` на staging (тестовый бот) — не из production.

## Загрузка фотографий

Отдельного скрипта нет намеренно: загрузка идёт **напрямую в хранилище** по подписанной ссылке, наш API участвует только в выдаче ссылки и подтверждении. Проверяется вручную по чеклисту: 50 одновременных загрузок с нескольких устройств.
